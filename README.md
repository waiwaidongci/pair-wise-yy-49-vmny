# 高校课程标准映射与课程改革审阅平台

面向教研人员、课程负责人和院系审阅人的课程图谱平台，支持培养目标、毕业要求、课程单元、教学活动、考核任务映射，以及有向图检查、覆盖矩阵、拖拽连边、自动保存、批量审核和课程地图导出。

## 技术栈

SvelteKit + Skeleton UI + Svelte stores + SvelteKit Form Actions + TanStack Query + Zod + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62049`，生产构建使用 `npm run build`。

## 核心工作流

- 在培养目标、毕业要求、课程、单元和考核之间建立有向映射。
- 自动检查前置关系、覆盖缺口、重复映射和不完整考核证据。
- 课程负责人提交修订，院系审阅人逐条退回、附议或要求补充证据。
- 比较版本覆盖变化，恢复草稿并导出专业课程地图。

## 离线审阅单合并

在「改革审阅」页处理课程组带出的离线审阅单（JSON）：

- **导出**：从最新冻结版本带出离线单，随行携带冻结基线（状态/证据/意见），教师离线修改后再导回。
- **预检先行**：导入时不写草稿，先检查冻结版本是否一致、条目是否缺失、同一项是否出现两份离线决定；命中任一问题整张单带原因进入待处理区，当前草稿保持不变，可重新预检或移出。
- **逐项冲突确认**：以冻结基线做三方比对。只有一方改过的字段自动采用该方；本地与离线**双方都改过**同一字段时，界面并列显示冻结值、本地值、离线值，由审阅人逐字段选择，后到内容不会整条覆盖。
- **幂等导入**：同一单号（待处理区或合并记录中已存在）重复导入只处理一次。
- **失败保留现场**：全部确认前不可合并；合并后校验不过（如退回意见过短）时保留会话与已确认选择，重试从已解决项继续。
- **原子提交**：全部确认后，审阅项、草稿、修订号（R12→R13）、合并记录与新冻结快照在同一次提交更新。
- **可追溯**：合并记录保留每个字段的来源（取本地/取离线）、旧值与新值；各冻结版本的映射权重和旧意见快照可随时展开对比。

离线单与合并的纯领域逻辑位于 `src/lib/offline.ts`，`scripts/test-offline.ts` 覆盖上述场景的断言复核。
